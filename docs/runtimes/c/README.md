# C ABI

Crate `writerslogic-warm-c` (`bindings/c`), header `bindings/c/include/writerslogic_warm.h` (generated by `bindings/c/scripts/gen-header.sh`, cbindgen). Libraries: `cdylib`, `staticlib`, `rlib`. Go, Java and .NET wrap this ABI.

## Quickstart
Build the library, compile [`bindings/c/examples/quickstart.c`](../../../bindings/c/examples/quickstart.c) against the header, and run it on a new store directory. `bindings/c/tests/c/run.sh` compiles and runs the same file in CI.

```sh
export CARGO_TARGET_DIR=/path/to/private/target
cargo build --release --manifest-path bindings/c/Cargo.toml
cc -std=c11 -Ibindings/c/include bindings/c/examples/quickstart.c -o quickstart \
  -L"$CARGO_TARGET_DIR/release" -lwriterslogic_warm_c -lpthread -lm
LD_LIBRARY_PATH="$CARGO_TARGET_DIR/release" DYLD_LIBRARY_PATH="$CARGO_TARGET_DIR/release" \
  ./quickstart ./warm-c-data     # prints: harbor <score>
```

```c
/* Copyright 2024-2026 WritersLogic Contributors */
/* SPDX-License-Identifier: Apache-2.0 */

/* Open a store, ingest two documents, search, free. docs/runtimes/c/README.md shows this file;
   bindings/c/tests/c/run.sh compiles and runs it. Usage: quickstart STORE_DIR */

#include <stdio.h>
#include <string.h>

#include "writerslogic_warm.h"

static warm_str_t str(const char *s) { return (warm_str_t){(const uint8_t *)s, strlen(s)}; }

static int fail(const char *what) {
  fprintf(stderr, "%s failed (%d): %s\n", what, warm_last_error_code(), warm_last_error_message());
  return 1;
}

int main(int argc, char **argv) {
  if (argc != 2) {
    fprintf(stderr, "usage: %s STORE_DIR\n", argv[0]);
    return 2;
  }

  warm_store_t *store = NULL;
  if (warm_store_open(str(argv[1]), 2048, NULL, &store) != WARM_OK) return fail("open");

  warm_document_t docs[2];
  memset(docs, 0, sizeof docs);
  docs[0].id = str("harbor");
  docs[0].text = str("The harbor opens at six in the morning.");
  docs[1].id = str("market");
  docs[1].text = str("The market closes at noon on Sundays.");
  if (warm_store_ingest(store, docs, 2, NULL) != WARM_OK) {
    fail("ingest");
    warm_store_close(store);
    return 1;
  }

  warm_search_options_t options;
  warm_search_options_init(&options);
  options.k = 1;
  warm_results_t *results = NULL;
  if (warm_store_search(store, str("when does the harbor open"), &options, &results) != WARM_OK) {
    fail("search");
    warm_store_close(store);
    return 1;
  }

  for (size_t i = 0; i < warm_results_count(results); i++) {
    warm_result_t hit;
    if (warm_results_get(results, i, &hit) != WARM_OK) continue;
    /* Strings are length-prefixed and not NUL terminated. */
    printf("%.*s %.3f\n", (int)hit.document_id.len, (const char *)hit.document_id.ptr, hit.score);
  }

  warm_results_free(results);
  return warm_store_close(store) == WARM_OK ? 0 : fail("close");
}
```

Every handle the library returns is released by its own call: `warm_results_free` for a result set, `warm_store_close` for a store. Strings in a hit borrow from the result set, so copy them before freeing it.

## Surface
open/close store (path, dimensions, encryption key, signing, audit, embedding space), batch ingest (BM25 `title_weight`, chunking, optional embeddings, metadata JSON), search (k, candidate limit, filter, source URI, document ids, query embedding, lexical/semantic weights, fusion `blend`/`rrf`, `bm25_k1`, `bm25_b`), delete, stats, security status (encryption active), flush, compact, maintain, snapshot (verified point-in-time copy), chunk a document without a store.

## Contract
- Every fallible call returns `warm_status_t` (0 = `WARM_OK`); the failing thread's `hms1_last_error_code()` and `hms1_last_error_message()` describe it. The slot is per thread: read it right after the call on the same OS thread.
- No panic crosses the boundary (`catch_unwind`, `WARM_ERR_PANIC`).
- `WARM_ERR_MUTATION_COMMITTED` (11) means the data committed but a later effect failed; `WARM_ERR_MUTATION_UNCERTAIN` (12) means durability could not be established or rolled back. Reopen and reconcile stable record IDs before retrying either outcome.
- Strings are `warm_str_t` (pointer + length, UTF-8, not NUL terminated). NULL pointer with length 0 means "absent". Lengths are bounded (`WARM_MAX_BUFFER_BYTES` 1 GiB, `WARM_MAX_ARRAY_LEN` 2^24); nothing is allocated from a caller-supplied size.
- Zero-initialised option structs mean all defaults (set `struct_size`, or call `hms1_*_options_init`). Numeric search overrides are honoured only when their `WARM_SEARCH_SET_*` flag is set. Structs that begin with `struct_size` grow append-only; out-structs (`stats`, `security_status`) are filled only up to the caller's `struct_size`.
- Thread safety: a store handle is safe from any number of threads. `hms1_store_close` may run while calls are in flight; they finish first. Handles are never-reused tokens: a stale handle returns `WARM_ERR_INVALID_HANDLE`, never aliasing a later store. Result/chunk sets are immutable; concurrent reads are fine, `free` must not race with reads, double free is undefined, NULL is ignored.
- A store directory is held by one handle at a time across processes (`WARM_ERR_LOCKED`).
- Ingest is atomic per batch. Snapshot blocks mutations (not searches) while copying, then verifies the copy before publishing it.

## Versioning
Symbols are `hms1_*` (ABI major in the name; unversioned `warm_*` aliases are macros, disable with `WARM_NO_ALIASES`). `hms1_abi_version()` returns `major<<16|minor<<8|patch`. Minor: new functions and appended struct fields. Major: new symbol prefix, so two majors can coexist in one process. Document and result structs are fixed in v1; changing them needs a new function.

## Build and test
```sh
export CARGO_TARGET_DIR=/path/to/private/target
bindings/c/tests/c/run.sh              # C program vs shared and static library
MODE=leaks bindings/c/tests/c/run.sh   # macOS leaks(1); MODE=valgrind on Linux
cargo test --manifest-path bindings/c/Cargo.toml   # header layout vs C compiler, counting-allocator leak test
bindings/c/scripts/package-native.sh [rid [rust-target]]   # release archive + sha256
```
Archive names: `writerslogic-warm-c-<version>-<rid>.tar.gz`, rid in `osx-arm64 osx-x64 linux-x64 linux-arm64 win-x64 win-arm64` plus `win-x64-gnu` (MinGW static library for Go on Windows).

## Verified here (macOS arm64)
C program with shared and static linking, `leaks`: 0 leaks; counting-allocator test (fails when results are not freed); layout test against the system C compiler; Rust 1.89 compile, clippy 1.99; `cargo check` for x86_64 Linux and x86_64 Windows MSVC. Linux/Windows execution is not verified locally (`.github/workflows/bindings.yml` runs it).

## Encrypted storage
With encryption on, the engine encrypts journal payloads and chunk text records in `documents.text`; format inspection reports the text segment header and encryption flag. This protects stored payload bytes at rest, not filesystem metadata, access patterns, backups or bytes already returned to the caller.
