## H-B-6 — exact-rational interval reference (open; H-B-4/H-B-5 prerequisite)
Limitation: numerical epsilon checks do not prove a serving certificate; rounded norm-minus-dot, error radii and incumbent thresholds can otherwise cause false pruning.
Mechanism: a scalar specification of directed IEEE binary32 interval operations using exact rational arithmetic and explicit binary32 endpoint selection; derive the sqrt-free certificate and seed kth upper bound from enclosed quantities, with an exact-rational fallback outside a declared domain.
Supported fast-reference domain:1..128 dimensions; finite binary32 coordinates that are zero or have magnitude2^-16..2^16; threshold0..2^48. Other finite inputs/dimensions fall back to exact rational L2; invalid shapes,negative thresholds,NaN/Inf fail explicitly. This domain is a proof boundary, not a change to benchmark eligibility.
Arithmetic contract: binary32 source bits have exact dyadic meaning; directed endpoints are selected by integer-bit search, independent of host rounding/FTZ/DAZ. Exact Fraction arithmetic models source reconstruction, while production mapping still needs a separate proof for actual intrinsics/environment.
Budget: fixed deterministic fixtures across dimensions99/100/101/127/128/129; zero,duplicate/tied,signed,magnitude-boundary,subnormal/extremefinite vectors; thresholds below/equal/above exact L2 plus strict far-point pruning. Cap180s,at most129coordinates/fixture,32768cached decoded endpoints and256cached quantized vectors; timeout writes a failure receipt. No benchmark or performance run; all fixtures are local generated correctness data.
Accept: zero false prunes against independent Fraction.from_float direct squared-distance oracle; reconstructed norms/error radii enclosed; seed kth upper bound never below true kth; signed/unsigned dot correction exact; all unsupported finite inputs take fallback and all invalid inputs fail; at least one supported strict pruning case executes.
Prediction: conservative reference passes every correctness invariant; false keeps are permitted, false prunes are not. Passing gives a specification and regression oracle, not a native exactness,throughput,8GiB or3600s claim.
Prior art: interval arithmetic plus triangle inequality; Intel directed-round intrinsic declarations and rounding-control source already archived in intel-directed-rounding.json. No new dependency or novelty claim.
Deliverable: interval_reference.py and check_interval_reference.py; parent runs the command below and records LOG. Specialist does not execute.

The mathematical score is exact real squared L2 over stored finite binary32 source values. Signed zero has the same value as positive zero. This does not establish parity with a separately rounded official ground-truth score or its tie policy; that instrument audit remains required. Shapes must match; coordinates must already be exactly representable binary32, and NaN/Inf fail explicitly. All finite sources outside the certificate domain use exact-rational distance comparisons; dimension129 is exercised as fallback, without truncation or padding.

The reference decodes sign/exponent/mantissa to dyadic fractions. Each rounding endpoint is selected among finite binary32 encodings by exact comparisons. Addition, subtraction and multiplication use outward endpoints, including all product signs; the square operation handles intervals crossing zero. Scale is the nearest binary32 value of `maxabs/127`, ties to even; zero vectors use the minimum normal scale and zero norm. Integer codes round exact source/scale ratios to nearest-even and clamp to[-127,127]. The reconstruction radius is the smallest binary32 value whose exact square encloses the rational squared reconstruction error. This is an offline metadata specification; its Fraction cost is not a serving proposal.

For each vector, `sx²*sum(zx²)` is enclosed by directed operations. The corrected dot `sum((zx+128)*zq)-128*sum(zq)` is exact and below2^24 in absolute value for dimension<=128. The lower reconstructed-distance endpoint is the nonnegative clamp of the downward norm-sum minus the upward scaled-dot endpoint. The threshold is rounded upward before its upward square root, radius additions and square. There is no assumed FMA or reassociation. Generic interval products provide the required sign handling when the corrected dot is negative; a zero dot bypasses scale multiplication.

If `L <= ||xhat-qhat||²` and `R >= (sqrt(U)+ex+eq)²`, then `L>R` implies `||x-q||>sqrt(U)` by the triangle inequality. Equality always retains the row. To form `U`, compute an upper enclosure `ui>=di` of every incumbent source distance and take the kth smallest `ui`. At least k incumbent records have actual distance<=U; therefore the live-set kth distance is also<=U. Duplicate vectors remain distinct incumbent records. This scalar reference returns no final top-k IDs; exact tie resolution is still necessary in serving.

Python's [struct format documentation](https://docs.python.org/3/library/struct.html#format-characters) specifies binary32 for `f`; its [Fraction documentation](https://docs.python.org/3/library/fractions.html#fractions.Fraction.from_float) preserves the input float's exact value and [round](https://docs.python.org/3/library/fractions.html#fractions.Fraction.__round__) chooses nearest-even. The independent checker uses `Fraction.from_float` and direct coordinate differences; it does not call the reference's bit decoder or exact-distance helper. Endpoint optimality, error/norm enclosures, signed correction, strict tie behavior and composition with kth thresholds are checked separately.

Intel's [directed-round intrinsic definitions](https://www.intel.com/content/dam/develop/public/us/en/include/intrinsics-guide/data-latest.xml), pinned in `intel-directed-rounding.json` at SHA256 `6762a50652a35ef663fd532ed83b789d19bbc2ac7e94b1771f19d666d96c2c30`, describe add/subtract/multiply/sqrt rounding controls. A future native implementation must preserve the specified operation ordering, prove actual metadata generation, establish/restore appropriate FTZ/DAZ state, handle underflow and overflow lanes safely, and compare against this oracle. Python Fraction endpoints avoid those machine modes; they do not validate their native implementation.
